<h1>Project_AIDA</h1>

### 概要
AIDA（あいだ）は、友人や恋人など、大切な人との間で写真を手軽に共有できる写真共有サービスです。
一度設定するだけで、撮影した写真を相手と自然に共有できるため、SNSへの投稿やメッセージアプリで写真を選んで送るといった手間を減らすことができます。
写真を「送る」のではなく、写真を通して大切な人との「あいだ」をつなぐことを目指しています。

### AIDAが目指すもの
このサービスは、友人や恋人との関係の中で、
「今日撮った写真を送ってくれないかな？」
「もっと気軽に、撮った写真をすぐ共有できる方法はないだろうか？」
という小さな疑問からスタートしました。
SNSに投稿したり、メッセージアプリで写真を選んで送ったりするような手間をかけずに、撮った写真を大切な人と自然に共有できる方法を作りたい。
それが、AIDAの出発点です。

AIDAが目指しているのは、ユーザーが「写真を送らなければ」と意識したり、面倒に感じたりすることなく、一度設定するだけで、
写真を通じて大切な人との日常や感情を自然に共有できるサービスです。
写真を「送る」という行為そのものを減らし、写真が自然に二人の間を行き来する。
そんな、"人と人とのあいだ"をつなぐサービスを目指しています。
